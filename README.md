# Calibre-ZUO

一个使用 [zuo.cc](https://zuo.cc) API 作为数据源的 Calibre 网文刮削工具。

## 功能

- 按书名搜索候选，回填标题、作者、封面、简介、标签、评分、出版社、ISBN、出版日期。
- 独立下载封面。
- 通过标识符 `zuo-novel-id` 精确回填与二次刮削去重。
- 自定义列：网文字数、连载状态码、首发站、首订数。
- 内置小时 + 分桶限速，保护站点后端。

## 安装

1. 生成插件包：

   ```bash
   python build.py
   ```

   产出 `out/Calibre-ZUO.zip`。

2. 在 Calibre 中：**首选项 → 插件 → 从文件加载插件**，选择生成的 zip。

3. 在「获取元数据 / 下载封面」的插件列表里勾选 Calibre-ZUO，并可按需配置每小时请求上限。

## 使用

- **下载元数据和封面**：选中书籍 → 编辑元数据 → 下载元数据和封面。
- **仅下载元数据**：编辑元数据 → 下载元数据。
- **仅下载封面**：编辑元数据 → 下载封面。

## 目录结构

```
calibre-zuo/
├─ src/
│  └─ __init__.py     # Calibre Source 插件（identify / cover / 配置 / 自定义列）
├─ build.py           # zip 打包
└─ README.md
```

## 数据源

所有数据均来自 [zuo.cc](https://zuo.cc) 的公开只读接口。请合理配置请求频次，避免对站点造成压力。
